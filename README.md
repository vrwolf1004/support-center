# 소개

제품 사용에 필요한 안내와 도움을 제공합니다.

## 크롬 확장

- [1Hour1Word](./#docs%2F1hour1word%2FREADME.md) — 매 시간 한 단어씩 배우는 외국어 학습 확장
- [SubDash](./#docs%2Fsubdash%2FREADME.md) — 월별 구독비를 타임라인으로 관리하는 확장
- [StockPulse](./#docs%2Fstockpulse%2FREADME.md) — 주가 추적 및 변동 알림 확장
- [PicHunter](./#docs%2Fpichunter%2FREADME.md) — 웹페이지 이미지 다운로드 확장
- [Help Me Hide](./#docs%2Fhelpmehide%2FREADME.md) — 텍스트 암호화 숨김 확장
- [Look At The Sky](./#docs%2Flookatthesky%2FREADME.md) — 전체화면으로 하늘 사진을 감상하는 휴식 확장
- [DummyUp](./#docs%2Fdummyup%2FREADME.md) — 필드명과 타입을 지정해 더미 JSON 데이터를 생성하는 확장
- [KeepSpotlight](./#docs%2Fkeepspotlight%2FREADME.md) — Windows Spotlight 잠금화면 이미지를 탐색하고 저장하는 확장
- [AI Usage](./#docs%2Faiusage%2FREADME.md) — Claude.ai와 GitHub Copilot 사용량을 한 번에 확인하는 확장

## 사이트

- [PickLayer](./#docs%2Fpicklayer%2FREADME.md) — 크로스플랫폼 UI 컴포넌트 라이브러리
- [No Banner](./#docs%2Fnobanner%2FREADME.md) — 사진 한 장으로 불법 현수막 신고 정보를 준비하는 웹 도구
- [pickspinners](./#docs%2Fpickspinners%2FREADME.md) — 스피너 커뮤니티

## herdr 플러그인

- [herdr-devrun](https://github.com/vrwolf1004/herdr-devrun) — 프로젝트 개발 서비스(백엔드, 프론트엔드 등)를 한 대시보드에서 실행·관리
- [herdr-obsidian](https://github.com/vrwolf1004/herdr-obsidian) — Obsidian 보관함을 herdr pane에서 탐색·읽기·편집·검색
- [herdr-simple-git](https://github.com/vrwolf1004/herdr-simple-git) — AI 없이 git pull, commit, push 실행
- [herdr-stockpulse](https://github.com/vrwolf1004/herdr-stockpulse) — 주가 현재가와 추세를 대시보드·사이드바에 표시
- [herdr-timekit](https://github.com/vrwolf1004/herdr-timekit) — 현재 시각, 세계 시간, 타이머, 카운터를 사이드바에 표시
- [herdr-ai-feedbag](https://github.com/vrwolf1004/herdr-ai-feedbag) — Claude Code, Copilot, Codex, Gemini 사용량을 사이드바에 표시
- [herdr-radio](https://github.com/vrwolf1004/herdr-radio) — 인터넷 라디오를 herdr 안에서 재생
- [herdr-talk](https://github.com/vrwolf1004/herdr-talk) — herdr 안에서 다른 PC 사용자와 채팅 (보안 보완 작업 중이니 민감한 대화에는 사용 전 확인)
- [herdr-tetris](https://github.com/vrwolf1004/herdr-tetris) — 터미널 게임 (테트리스, 래더, 스네이크, 지뢰찾기)
- [herdr-dock-grid](https://github.com/vrwolf1004/herdr-dock-grid) — 도크 플러그인들이 쓰는 pane 배치를 관리하는 공용 모듈
