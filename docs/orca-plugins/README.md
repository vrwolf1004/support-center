# Orca 플러그인

Orca 사이드바에서 쓰는 플러그인 모음입니다.

## 설치

Orca에서 각 플러그인의 **Open in Orca** 버튼을 누르거나, 직접 설치합니다.

1. Orca **설정 → 플러그인**을 엽니다.
2. 마켓플레이스를 한 번 추가합니다. URL: `https://github.com/stablyai/orca-community-plugins.git`, Ref: `main`
3. 플러그인 이름을 검색한 뒤 **Install**을 누릅니다.

요구사항: Orca 1.4.246 이상. 플러그인은 커뮤니티 제작이며 Orca에서 검수하지 않았습니다. 설치 전에 Orca가 요청하는 권한을 확인하세요.

## 탐색과 읽기

### Obsidian for Orca

옵시디언(Obsidian) 보관함을 Orca 사이드바에서 탐색하고 읽을 수 있습니다.

- 저장소: [orca-obsidian](https://github.com/vrwolf1004/orca-obsidian)
- Orca 페이지: [orca.dev/plugins/vrwolf1004/orca-obsidian](https://orca.dev/plugins/vrwolf1004/orca-obsidian)
- 권한: 전체 접근 (파일 읽기, 네트워크, 자체 데이터 저장)

## 미디어

### Radio for Orca

Orca 사이드바에서 인터넷 라디오를 재생합니다.

- 저장소: [orca-radio](https://github.com/vrwolf1004/orca-radio)
- Orca 페이지: [orca.dev/plugins/vrwolf1004/orca-radio](https://orca.dev/plugins/vrwolf1004/orca-radio)
- 권한: 전체 접근 (파일 읽기, 네트워크, 다른 프로그램 실행)

## 게임

### Tetris for Orca

F1을 누르면 새 화면이 열립니다. 레트로 테트리스, 래더, 스네이크, 지뢰찾기를 Orca 사이드바에서 즐길 수 있습니다.

- 저장소: [orca-tetris](https://github.com/vrwolf1004/orca-tetris)
- Orca 페이지: [orca.dev/plugins/vrwolf1004/orca-tetris](https://orca.dev/plugins/vrwolf1004/orca-tetris)
- 권한: 패널 추가 (플러그인 코드를 Orca 안에서 실행해 화면을 그림)
