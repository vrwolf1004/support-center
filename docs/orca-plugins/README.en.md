# Orca Plugins

Plugins for the Orca sidebar.

## Install

Click **Open in Orca** on a plugin's page, or install it by hand.

1. Open Orca **Settings → Plugins**.
2. Add the marketplace once. URL: `https://github.com/stablyai/orca-community-plugins.git`, Ref: `main`
3. Search for the plugin name and choose **Install**.

Requirement: Orca 1.4.246 or later. These plugins are community-made and not reviewed by Orca. Check the access Orca asks for before you install.

## Browse and Read

### Obsidian for Orca

Browse and read your Obsidian vaults from the Orca sidebar.

- Repository: [orca-obsidian](https://github.com/vrwolf1004/orca-obsidian)
- Orca page: [orca.dev/plugins/vrwolf1004/orca-obsidian](https://orca.dev/plugins/vrwolf1004/orca-obsidian)
- Access: full access (read files, use the network, store its own data)

## Media

### Radio for Orca

Play internet radio from the Orca sidebar.

- Repository: [orca-radio](https://github.com/vrwolf1004/orca-radio)
- Orca page: [orca.dev/plugins/vrwolf1004/orca-radio](https://orca.dev/plugins/vrwolf1004/orca-radio)
- Access: full access (read files, use the network, run other programs)

## Games

### Tetris for Orca

Press F1 and a new view opens. Play Retro Tetris, Ladder, Snake, and Minesweeper in the Orca sidebar.

- Repository: [orca-tetris](https://github.com/vrwolf1004/orca-tetris)
- Orca page: [orca.dev/plugins/vrwolf1004/orca-tetris](https://orca.dev/plugins/vrwolf1004/orca-tetris)
- Access: adds a panel (runs the plugin's code inside Orca to draw its view)
