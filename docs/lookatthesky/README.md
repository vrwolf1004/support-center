# Look At The Sky

잠깐 쉬어가세요. 전체화면으로 하늘 사진을 감상하는 Chrome 확장입니다.

## 설치

1. 확장을 설치합니다.
2. 툴바에 Look At The Sky 아이콘이 나타나면 설치 완료입니다.

## 사용법

### 하늘 사진 감상 시작

1. 툴바의 아이콘을 클릭합니다.
2. 원하는 **이미지 제공처**를 선택합니다.
3. **Start Viewing** 버튼을 클릭하면 전체화면으로 하늘 사진이 열립니다.

### 이미지 제공처 선택

| 제공처 | 설명 |
|--------|------|
| Wikimedia Commons | 위키미디어 공개 이미지 (기본값) |
| Openverse | Creative Commons 라이선스 이미지 |

### 설정 (Settings)

툴바 아이콘 클릭 → **Settings** 버튼으로 세부 옵션을 조정할 수 있습니다.

#### 슬라이드쇼 설정
- **Slide Interval**: 사진이 자동으로 넘어가는 시간 간격 (기본: 8초)
- **Mode**: 슬라이드쇼(자동) 또는 수동 전환 선택

#### 휴식 타이머
- **Enable Timer**: 일정 시간 후 자동으로 전체화면을 닫는 타이머 활성화
- **Timer Interval**: 타이머 시간 설정 (기본: 20분)

#### 이미지 품질
- **Resolution**: 이미지 해상도 선택 (full 등)

#### 검색 키워드 커스터마이징
제공처별로 맑은 날(Day)과 흐린 날(Cloudy)에 표시할 이미지의 검색 키워드를 직접 설정할 수 있습니다.
- 비워두면 기본 키워드를 사용합니다.
- 예: `sunset`, `storm clouds`, `golden hour sky`

#### 캐시 관리
- **Cached Images**: 현재 캐시된 이미지 수 표시
- **Clear Cache**: 캐시된 이미지를 초기화하고 다음 실행 시 새 이미지를 불러옵니다.

## 기능

| 기능 | 설명 |
|------|------|
| 전체화면 감상 | 브라우저 전체화면으로 하늘 사진 표시 |
| 다중 제공처 | Wikimedia, Openverse 중 선택 |
| 슬라이드쇼 | 설정한 간격으로 사진 자동 전환 |
| 휴식 타이머 | 일정 시간 후 자동 종료 |
| 키워드 커스터마이징 | 제공처별 검색 키워드 직접 설정 |
| 이미지 캐시 | 빠른 로딩을 위해 이미지 로컬 캐시 |

## 업데이트

- Chrome 확장 프로그램은 자동으로 업데이트됩니다.
- 수동: `chrome://extensions` → **업데이트** 클릭
