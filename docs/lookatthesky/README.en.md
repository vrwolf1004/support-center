# Look At The Sky

Take a short break while enjoying sky photos in fullscreen.

## Installation

1. Visit the [Chrome Web Store page](https://chromewebstore.google.com/detail/lagkfaiecnddccbdgijgahcpohfjohga?utm_source=item-share-cb) to install.
2. Installation is complete when the Look At The Sky icon appears in the toolbar.

## Usage

### Start Viewing Sky Photos

1. Click the icon in the toolbar.
2. Select your preferred **image provider**.
3. Click the **Start Viewing** button to open sky photos in fullscreen.

### Image Providers

| Provider | Description |
|----------|-------------|
| Wikimedia Commons | Public domain images from Wikimedia (default) |
| Openverse | Creative Commons licensed images |

### Settings

Click the toolbar icon → **Settings** button to adjust detailed options.

#### Slideshow Settings
- **Slide Interval**: Time between automatic photo transitions (default: 8 seconds)
- **Mode**: Choose between slideshow (automatic) or manual navigation

#### Break Timer
- **Enable Timer**: Activate a timer to automatically close the fullscreen after a set duration
- **Timer Interval**: Set the timer duration (default: 20 minutes)

#### Image Quality
- **Resolution**: Select image resolution (e.g., full)

#### Custom Search Keywords
Set custom search keywords for each provider — separately for clear-day (Day) and overcast (Cloudy) conditions.
- Leave blank to use the default keywords.
- Examples: `sunset`, `storm clouds`, `golden hour sky`

#### Cache Management
- **Cached Images**: Shows the number of currently cached images
- **Clear Cache**: Clears cached images so new ones are fetched on the next launch

## Features

| Feature | Description |
|---------|-------------|
| Fullscreen Viewing | Display sky photos in browser fullscreen mode |
| Multiple Providers | Choose between Wikimedia and Openverse |
| Slideshow | Automatically advance photos at a set interval |
| Break Timer | Auto-close after a specified duration |
| Keyword Customization | Set custom search keywords per provider |
| Image Cache | Locally cache images for fast loading |

## Updates

- Chrome extensions update automatically.
- Manual: `chrome://extensions` → Click **Update**

## Privacy Protection

Look At The Sky does not transmit any personal data to external servers.  
For details, see the [Privacy Policy](docs/lookatthesky/privacy.html).
