# pickspinners

> A free HTML/CSS loading spinner library for web developers

## 📖 Overview

**[pickspinners.com](https://www.pickspinners.com/)** is a loading spinner library you can drop straight into your web pages. Browse 120+ spinners by category and copy the CSS code in one click.

## 🎨 Key Features

### Spinners
- **120+ spinners** — 12 categories (circular, dots, bars, Korean-style, deep sea, constellation, and more)
- **One-click copy** — CSS code is copied automatically

### Favorites
- **Choose up to 3** and register by email

### Multi-language Support
- **8 languages** (Korean, English, Japanese, Spanish, French, German, Russian, Chinese)

### Responsive Design
- **Fully responsive** across mobile, tablet, and desktop
