# pickspinners

웹 개발자를 위한 무료 HTML/CSS 로딩 스피너 라이브러리입니다.

## 배포 URL

- 사이트: [www.pickspinners.com](https://www.pickspinners.com/)
- 개인정보 처리방침: [www.pickspinners.com/privacy](https://www.pickspinners.com/privacy)

## 주요 기능

- **120개 이상 스피너**: 12개 카테고리별 분류 (원형, 점, 막대, 한국식, 깊은바다, 별자리 등)
- **원클릭 복사**: CSS 코드 자동 복사
- **즐겨찾기**: 최대 3개 선택 후 이메일 등록
- **다국어**: 8개 언어 지원 (한국어, 영어, 일본어, 스페인어, 프랑스어, 독일어, 러시아어, 중국어)
- **반응형**: 모바일, 태블릿, 데스크톱 지원
- **오픈소스**: CC0 라이선스 (LICENSE.txt)
- **자동 배포**: GitHub Actions + Cloudflare Pages/Workers
