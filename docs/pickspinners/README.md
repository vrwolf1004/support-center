# pickspinners

> 웹 개발자를 위한 무료 HTML/CSS 로딩 스피너 라이브러리

## 📖 개요

**[pickspinners.com](https://www.pickspinners.com/)**은 웹 페이지에 바로 붙여 쓸 수 있는 로딩 스피너 라이브러리입니다. 120개 이상의 스피너를 카테고리별로 골라 CSS 코드를 한 번에 복사해 사용할 수 있습니다.

## 🎨 주요 특징

### 스피너
- **120개 이상 스피너** — 12개 카테고리 (원형, 점, 막대, 한국식, 깊은바다, 별자리 등)
- **원클릭 복사** — CSS 코드 자동 복사

### 즐겨찾기
- **최대 3개 선택** 후 이메일 등록

### 다국어 지원
- **8개 언어** 지원 (한국어, 영어, 일본어, 스페인어, 프랑스어, 독일어, 러시아어, 중국어)

### 반응형 디자인
- 모바일, 태블릿, 데스크톱 **완전 대응**

## 🛠️ 기술 스택

| 분야 | 기술 |
|------|------|
| **Frontend** | HTML5, CSS3 |
| **호스팅** | Cloudflare Pages |
| **배포** | GitHub Actions + Cloudflare Pages/Workers |

## 🔐 개인정보 보호

회원가입은 선택 사항입니다. 즐겨찾기 등록이나 커뮤니티 폼 이용 시 이메일 주소를 수집하며, 방문 분석을 위해 Google Analytics를 사용합니다. 자세한 내용과 이메일 삭제 요청 방법은 [개인정보 처리방침](https://www.pickspinners.com/privacy)을 참고하세요.
