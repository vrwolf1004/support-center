# No Banner (불법 현수막 신고 도우미)

사진 한 장으로 불법 현수막 신고 정보를 빠르게 준비하는 웹 도구입니다.  
사진 업로드부터 신고서 작성까지 한 흐름으로 진행할 수 있습니다.

## 사용법

### 1단계 — 사진 업로드

1. [사이트에 접속](https://snap.picklayer.net)합니다.
2. **신고하기** 버튼을 클릭합니다.
3. 불법 현수막을 촬영한 사진을 업로드합니다.

### 2단계 — 정보 추출

업로드한 사진에서 자동으로 아래 정보를 추출합니다.

| 항목 | 설명 |
|------|------|
| 위치 정보 | 사진의 GPS EXIF 데이터에서 주소 추출 |
| 촬영 일시 | 사진 메타데이터(EXIF)에서 자동 추출 |
| 텍스트(OCR) | 현수막에 적힌 문자를 자동으로 인식 |
| 얼굴 블러 | 사진 속 인물 얼굴을 자동으로 흐리게 처리 |

> GPS 정보가 없는 경우, 지도에서 위치를 직접 선택하거나 주소를 입력할 수 있습니다.

### 3단계 — 신고서 작성

추출된 정보를 바탕으로 신고 내용을 편집한 뒤, 아래 공식 신고 채널에 제출합니다.

**전국 신고 채널**

| 기관 | 특이사항 |
|------|----------|
| 안전신문고 | 불법 광고물·현수막 전용, 사진 첨부 가능 |
| 국민신문고 | 모든 행정기관 대상 민원 |
| 중앙선거관리위원회 | 선거 관련 현수막, 익명 신고 가능 |
| 경찰청 112 | 비회원 신고 가능 |

## 주요 기능

| 기능 | 설명 |
|------|------|
| EXIF 위치 추출 | 사진의 GPS 데이터로 주소 자동 변환 |
| 얼굴 자동 블러 | 개인정보 보호를 위해 얼굴 자동 처리 |
| OCR 텍스트 인식 | 현수막 텍스트 자동 추출 |
| 신고 채널 안내 | 전국 및 지역별 신고 사이트 목록 제공 |

## 개인정보 보호

No Banner는 업로드한 사진 및 개인 데이터를 외부 서버로 전송하지 않습니다.  
모든 처리(EXIF 추출, 얼굴 감지, OCR)는 사용자 브라우저 내에서만 이루어집니다.  
자세한 내용은 [개인정보 처리방침](docs/nobanner/privacy.html)을 참고하세요.
